# Dataset

## Description

Dataset with experimental results from creating and destroying emulated network topologies using Ansible and Terraform.

## Structure

- **ansible/**: Execution time data with Ansible
  - `linear.csv`: Linear topology
  - `single.csv`: Single topology
  - `tree.csv`: Tree topology

- **terraform/**: Execution time data with Terraform
  - `linear.csv`: Linear topology
  - `single.csv`: Single topology
  - `tree.csv`: Tree topology

- **graficos/**: Results visualizations

## Reference

Data collected using [cloud-sdn-setup](https://github.com/vitorreiel/cloud-sdn-setup.git).
